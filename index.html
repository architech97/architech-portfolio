01 / IMAGE → FAMILYEXPERIMENTAL DESKTOP

ArchiTECH-I3D

A photo is the starting point.

A desktop workspace for turning a reference photo or an existing mesh into a reviewed 3D asset and a Revit family. Geometry, appearance and real-world scale stay part of the same workflow.

Strengths

  • Choose your starting point. Use local generation, a cloud service, or an existing mesh.
  • Keep control of the asset. Set a known measurement, review proportions and reuse saved geometry for material comparisons.
  • Finish inside Revit. A thin connector handles approved family creation, saving, loading and visible placement.

How it works

  1. PrepareChoose a photo or mesh and review its mask.
  2. Set upName the asset, set a known size and choose the geometry route.
  3. ReviewApply or preserve appearance, then inspect geometry and dimensions.
  4. ExportApprove the Revit export, save the family, load it and place an instance.

The current interface is the standalone Windows desktop app. Representative family export and placement checks are documented for Revit 2024; generation quality and recipient hardware still need review.

02 / INTENT → VERIFIED ACTIONPILOT BUILD

ArchiTECH-MCP

Give an agent the right tools.

A family of host-specific connectors for Revit, Rhino, SketchUp, AutoCAD and Blender. MCP connects an AI client to the tools and current document or scene in the application where the work happens.

Strengths

  • Discover tools in context. Inspect the active document or scene and find the capabilities available for the task.
  • Keep execution native. Each connector uses its host application's execution path, with approval-aware writes and host-specific recovery rules.
  • Check what changed. Independent readback helps assess the final state, rather than treating an accepted request as proof of success.

Host workflows

Revit
Model context, modelling and documentation operations.
Rhino
Geometry creation, transforms, object readback and native undo/redo.
SketchUp
Geometry tools, transforms and world-space bounds checks.
AutoCAD
Drafting, layers, blocks and DXF workflows.
Blender
Scene inspection, object operations and guarded execution.

How it works

  1. ConnectAn MCP client requests context from the appropriate host connector.
  2. DiscoverFind the relevant capability and check its expected inputs.
  3. ExecuteRequest the operation through the host's approval and execution rules.
  4. VerifyRead the resulting document or scene state and return the outcome.

Documented pilot checks cover selected Revit level operations, Rhino object edits and undo/redo, SketchUp geometry bounds, AutoCAD entity edits, and Blender scene operations. Coverage varies by host; these checks do not certify every tool, version or installation.

03 / LANGUAGE → WORKFLOWPILOT BUILD

ArchiTECH-Assistant

Ask. Search. Build.

A desktop AI workspace with three clear modes: Ask for an answer, Search for available tools, or Build a task through a planning loop. Choose a configured local or server model to suit the work.

Strengths

  • Choose the mode for the task. Ask can answer without an open Revit document; model work uses the separate MCP connector.
  • Discover before acting. Search current capabilities instead of relying only on remembered tool names.
  • Follow work through to a result. Build coordinates tool use while MCP retains Revit execution, approvals and verification.

How it works

  1. ChooseSelect Ask, Search or Build and the model connection.
  2. DescribeEnter the question or task in natural language.
  3. CoordinateFor model tasks, discover tools and send the planned actions through MCP.
  4. ReviewFollow execution and inspect the returned result against the model.

Representative installed-app checks cover a local-model answer, reading levels, and creating then deleting a disposable level with verification in Revit 2024. The current build remains a pilot.
