# HESA Studio — Residence in Vasant Kunj

Static, responsive presentation using the original HESA Studio PDF. Serve this directory using any static host; no build, API key, or installation required.

## Experience
- Selectable original exterior hero views and a direct floor-plan entry.
- Chapter navigation with source-backed project explanation.
- Ground, first and second floor furnished plans, exact numbered room keys and technical drawings.
- Fullscreen image inspection, original-size zoom, keyboard navigation and focus restoration.
- Four uncropped original exterior views and a user-started cinematic image sequence.
- Authentic HESA logo, studio introduction, four services, contact imagery and details.
- All 15 PDF slides available in the archive, plus unchanged original PDF.
- Reduced-motion support, optional motion toggle and touch-friendly controls.

The exploded-view section, 3D runtime and derived geometry data have been removed at the user's request. No reconstructed building models or unverified Blender stills are included. Every original design image, drawing and PDF remains unchanged. Source visuals are architectural renderings, not photographs of completed construction. Studio illustrations are explicitly distinguished from residence imagery.

Design research: Refero Spacelab editorial architecture layout, MANNA uncropped image presentation, and earlier Exo Ape type hierarchy. No external site imagery or code copied. Design imagery © HESA Studio.
