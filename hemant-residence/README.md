# Hemant Residence

A static, mobile-responsive architectural presentation based on the supplied HESA Studio PDF.

Open index.html or host this directory with any static web server. No build, backend, API key, or package installation is required.

## Interactions
- Three floor plans, furnished and technical drawing views
- Perspective tilt of the original flat plan (not a 3D reconstruction)
- Day and night exterior views
- Accessible fullscreen gallery with keyboard navigation
- Original PDF presentation

## Source and attribution
All project imagery and drawings are extracted from the supplied HESA Studio residence presentation. They are architectural visualizations, not photographs. Original design imagery remains attributed to HESA Studio. Website code is original; interaction direction draws on plan-to-perspective architectural storytelling without copying reference application source.

Google Fonts provides DM Sans and Italiana with local system-font fallbacks.
