## Design reference lock

The existing ArchiTECH brand art and drawing-set identity are the primary visual
source: midnight canvas, blue architectural imagery, system sans typography,
monospaced captions and fine borders. The user's reference,
https://github.com/adrianhajdin/award-winning-website, contributes only the ideas of
an image-led opening, one geometric reveal and an asymmetrical project composition.
No source, fonts, videos or brand imagery from that reference were imported.
Refero style searches returned no results; its bundled typography and motion
guides informed legibility, type hierarchy and restrained movement.

| Decision | Source / role | Reason |
| --- | --- | --- |
| Existing architecture plate as hero | Existing public `assets/bg-hero.jpg` | Immediate identity without a new media dependency |
| Large upright three-line title | User's BIM × Tech × AI brief; Refero typography craft | Clear hierarchy; system font loads immediately |
| Midnight canvas, ice text, blue metadata | Existing brand | Preserve identity; high-contrast reading surfaces |
| Asymmetrical project grid | Reference interaction principles | Give each named project its own story |
| Single clip reveal and gentle pointer tilt | Reference principles; Refero motion craft | Establish hierarchy without scroll blocking |
| Natural page scroll | Accessibility and mobile brief | Remove mandatory snap and long pinned waits |
| Public demo links | Owner's public LinkedIn recordings | Reachable evidence without private repository links |

Images on the project cards are explicitly labelled existing concept art, rather
than screenshots of the products. New images load lazily. The hero plate is
preloaded. No package installation or build system was added.

`node tests/mobile-layout-contract.mjs`. The browser check uses installed Edge,
tests 320/360/390/430px mobile and 1366px desktop, checks existing section layout,
